# 🛡️ CyberGuard AI

### Friendly AI Cybersecurity Assistant

CyberGuard AI is an AI-powered cybersecurity assistant designed to help users analyze suspicious messages, screenshots, and security alerts.

It uses **CrewAI-based AI agents**, cybersecurity analysis logic, and **Streamlit** to provide a simple and user-friendly security assessment.

---

## 🚀 Features

### 🔍 Message Analysis

Analyze suspicious messages, emails, alerts, and other text-based evidence.

### 🖼️ Screenshot Analysis

Upload screenshots of:

- Suspicious messages
- Emails
- Login pages
- Security alerts
- Phishing pages

The system extracts visible evidence from the screenshot and performs a cybersecurity risk assessment.

### 💬 Cybersecurity Chat

Ask cybersecurity-related questions and receive helpful defensive guidance.

### 🎓 Cybersecurity Learning

Learn about common cybersecurity threats, phishing indicators, account security, and safe online practices.

### 📊 Security Activity

Review investigation results and security activity generated by the application.

---

## 📊 Risk Levels

CyberGuard AI uses a risk score from **0–100**:

| Risk Score | Level | Meaning |
|------------|-------|---------|
| 🟢 0–33 | **SAFE** | No significant security-risk indicators detected |
| 🟡 34–69 | **SUSPICIOUS** | Some warning signs require further verification |
| 🔴 70–100 | **DANGEROUS** | Strong indicators of phishing, scam activity, or serious cybersecurity risk |

---

## 🧩 Threat Detection

CyberGuard AI can identify indicators such as:

- 🔑 Credential harvesting requests
- 🔐 Password requests
- 🔢 OTP / verification-code requests
- 🔗 Suspicious or unsecured URLs
- ⚠️ Urgent or high-pressure language
- 🚨 Account suspension or lock threats
- 💳 Financial information requests
- 🕵️ Possible impersonation
- 🔓 Suspicious login activity
- 🦠 Possible malware indicators

---

## 🤖 AI Architecture

The project uses **CrewAI** to organize AI agents for cybersecurity analysis.

### Security Analyst

Analyzes the provided evidence and identifies potential cybersecurity threats.

### Report Writer

Converts the analysis into a clear, user-friendly cybersecurity assessment.

The application also uses deterministic risk-scoring logic to help maintain consistent **SAFE, SUSPICIOUS, and DANGEROUS** classifications.
